# Contributing Guidelines

## Pull Request Rules
1. **Visual Proof Requirement**: Any pull request that modifies React components, HTML, Tailwind classes, or frontend layouts MUST include screenshots or screen recordings in the PR description demonstrating the rendered output.
2. **Reviewers & Assignees**: Ensure the relevant assignees and reviewers are added to PRs.
3. **Build Integrity**: Ensure `npm run build` succeeds without errors before opening a PR.
